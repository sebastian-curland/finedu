# פיננסיקס

אפליקציית אינטרנט ללימוד פיננסי לילדים, בעברית, פועלת גם ללא חיבור לאינטרנט.

## דרישות מקדימות

- [Node.js](https://nodejs.org/) מותקן במחשב (כולל `npx`).

אין צורך בהתקנת תלויות נוספות — האפליקציה כתובה כ-ES Modules סטטיים לחלוטין,
ללא שלב build, ללא bundler וללא ספריות npm.

## הפעלה

מתוך תיקיית הפרויקט, הריצו:

```bash
./start.sh
```

הסקריפט יציג את הכתובת המקומית (ולעיתים גם כתובת ברשת האלחוטית המקומית,
כדי לפתוח את האפליקציה ממכשיר נוסף כמו טאבלט) ויפעיל שרת סטטי באמצעות
`npx serve public`. פתחו את הכתובת שמוצגת בדפדפן.

בפעם הראשונה שמריצים את הסקריפט יש לוודא שיש לו הרשאות הרצה:

```bash
chmod +x start.sh
```

### מצב תצוגה — כל העולמות פתוחים

לצורך התרשמות מהירה או בדיקה, אפשר להריץ עם כל 12 העולמות פתוחים במפה,
בלי צורך לעבור את המבחנים אחד-אחד:

```bash
FINEDU_UNLOCK_ALL=1 ./start.sh
```

זה משפיע רק על מה שמוצג כפתוח במפה — לא "פותר" מבחנים, לא מוסיף נקודות
ולא מעניק תגים. הרצה רגילה של `./start.sh` (בלי המשתנה) חוזרת להתקדמות
הרגילה לפי פרופיל.

## מפתח API של Twelve Data (אופציונלי)

חלק מהכלים באפליקציה (מעקב שערי מניות ומטבעות) יכולים להשתמש ב-API חיצוני
בשם [Twelve Data](https://twelvedata.com/) כדי להציג נתוני שוק עדכניים.
זהו שלב **אופציונלי לחלוטין**.

כדי להפעיל את זה, יש להדביק מפתח API אישי בקובץ `public/config.js`, בשורה
מהצורה:

```js
export const TWELVE_DATA_API_KEY = 'your-key-here';
```

**האפליקציה עובדת באופן מלא גם בלי מפתח API ובלי חיבור לאינטרנט** — במקרה
כזה היא משתמשת בנתוני דמו מוכנים מראש במקום נתונים חיים.
